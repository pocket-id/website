**My Apps** lists the OIDC clients a user may sign in to, so it doubles as a start page for everything behind Pocket ID.
Users open it from the sidebar after signing in to Pocket ID.

<Screenshot name="my-apps" alt="The My Apps page with tiles for Nextcloud, Jellyfin, Grafana, Paperless-ngx, Gitea and Home Assistant" />

## Add an app to the dashboard

A client appears on the dashboard once it has a **Client Launch URL**, which is the address **Launch** opens.
Set it on the client's **General** tab under **Administration → OIDC Clients**, together with a logo for the tile.

The dashboard only shows clients that the user's groups [allow](/docs/configuration/allowed-groups).
**Show all apps** also lists the clients without a launch URL that the user signed in to before.

## Revoke access

When a user signs in to a client for the first time, they agree to share their details with it.
To take that back, they open the client's **⋯** menu on the dashboard and choose **Revoke Access**, and Pocket ID asks again on their next sign-in.
